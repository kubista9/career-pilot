# Career Pilot

A job-hunt assistant for Claude Code. One skill runs the daily routine: search job boards, drop duplicates, score each job honestly, track everything locally and prepare applications for you to review.

**Nothing is sent without your approval unless you switch auto-submit on for a route. It never creates accounts, logs in or messages anyone on its own.**

This repository is generic. Everything about you (profile, CV, rules, tracker) lives in a data dir outside the repo.

Work in progress. See [AGENTS.md](AGENTS.md) for how the repo is organised.
